# Семантический индекс слабо структурированной информации в применении к соцсетям
**Проект магистерской диссертации по направлению Data Science**

---

## 1. Концепция и проблематика

**Проблематика:** Классический анализ трендов в социальных сетях и системах сбора слабо структурированной информации опирается на методы прямого лексического совпадения (подсчет частотности слов, агрегация хештегов). Это приводит к доминированию глобального информационного шума: зарождающиеся локальные тренды (микро-тренды) и неочевидные семантические паттерны остаются невидимыми до момента перехода в мейнстрим. 

**Решение:** Разработка системы динамического ранжирования и извлечения знаний на базе реифицированного семантического графа. Вместо бинарной связи «пост-тег» используется многомерная оценка, объединяющая семантический вывод больших языковых моделей (LLM), статистическую уникальность тега и логарифмическую функцию темпорального угасания. Применение дифференциального исчисления к дискретным временным рядам снимков графа позволяет детектировать эмерджентные тренды на основе их относительного ускорения.

---

## 2. Архитектура данных: Реифицированный семантический граф

Для преодоления ограничений плоских структур применяется паттерн реификации. Связь между единицей контента и семантическим кластером выделяется в самостоятельный узел, инкапсулирующий метаданные нейросетевого вывода и временной контекст.

### Основные узлы и свойства:
*   `(:Post)`: Узел контента. Содержит сырые данные, метаданные автора и векторное представление (эмбеддинг).
*   `(:Tag)`: Узел семантической категории.
*   `(:TagAssignment)`: Узел реификации (Связь). Содержит свойства `semantical_weight` (уверенность LLM), `reasoning` (цепочка рассуждений, Explainable AI) и временную метку.
*   `(:IndexSnapshot)` и `(:TimeFrame)`: Узлы темпоральной фиксации для дискретизации состояний графа.

### Топология связей:
*   `(Post)-[:HAS_ASSIGNMENT]->(TagAssignment)-[:FOR_TAG]->(Tag)`
*   `(Post)-[:RELATED_TO {similarity_score}]->(Post)` — взвешенная связь косинусного расстояния между эмбеддингами постов.
*   `(Tag)-[:APPEARS_IN_TIMEFRAME {velocity, acceleration}]->(TimeFrame)` — агрегация исторических метрик динамики.

## 3. Математическая модель и система нормирования

Построение интегрального индекса популярности тега $I(t)$ требует строгой математической базы. Обоснование метрик опирается на методы функционального анализа, что позволяет корректно проецировать данные из различных пространств.

### 3.1. Векторные представления и гильбертовы пространства
Каждый пост $P_i$ отображается в непрерывное векторное представление $v_i$. Множество эмбеддингов рассматривается как элементы вещественного гильбертова пространства $\mathcal{H}$, где скалярное произведение определяет семантическую близость.
Для оценки связи между постами используется индуцированная норма $L_2$, нормированная на единичную сферу:
$$similarity(v_i, v_j) = \frac{\langle v_i, v_j \rangle}{\|v_i\|_2 \|v_j\|_2}$$

### 3.2. Компоненты интегрального индекса $I(t)$

Агрегированный вес тега $T_j$ в момент времени $t$ является линейной комбинацией трех нормированных функционалов:

**1. Семантический вес ($W_{sem}$):** 
Функционал уверенности модели генерации. Модель (LLM) выступает как нелинейный оператор, проецирующий текст поста в пространство тегов с весами в строгом диапазоне:
$$W_{sem}(P_i, T_j) \in [0, 1]$$

**2. Статистический вес ($W_{stat}$):**
Аналог метрики IDF для графовых структур. Для предотвращения доминирования высокочастотных компонент (глобальных трендов), распределение нормируется с использованием логарифмической шкалы.
$$W_{stat}(T_j) = \frac{\log(C_{local}(T_j) + 1)}{\log(C_{max} + 1)}$$
*Где $C_{local}$ — количество постов с данным тегом в текущем окне, а $C_{max}$ — супремум количества постов для доминирующего тега в графе.*

**3. Темпоральный вес ($W_{temp}$):**
Ограниченный функционал затухания. Использование логарифмической функции вместо жесткой экспоненциальной позволяет сохранить «длинный хвост» исторической памяти системы.
$$W_{temp}(t) = \frac{\log(1 + (t_{current} - t_{last\_used}))}{\log(1 + T_{max})}$$

**Интегральный индекс:**
$$I(t) = \alpha W_{sem} + \beta W_{stat} + \gamma W_{temp}$$
*(Коэффициенты $\alpha, \beta, \gamma$ подбираются эмпирически таким образом, чтобы $\|I\| \le 1$).*

## 4. Динамический анализ на дискретной сетке

Для обнаружения трендов граф генерирует серию дискретных состояний (снимков) $S_{t_0}, S_{t_1}, \dots, S_{t_n}$ с шагом $\Delta t$. Переход между снимками описывается эволюцией значений $I(t)$.

Поскольку данные социальных сетей зашумлены стохастическими выбросами, прямое численное дифференцирование (через конечные разности) приводит к неконтролируемому росту ошибки. 

### 4.1. Сглаживание и аппроксимация
Дискретный ряд $I(t)$ локально аппроксимируется непрерывным полиномом методом наименьших квадратов с помощью **фильтра Савицкого — Голея**. Это позволяет рассматривать динамику индекса как гладкую функцию и брать аналитические производные без потери фазы сигнала.

### 4.2. Детектирование трендов
*   **Макро-тренды (Глобальная повестка):** Выявляются через сортировку по абсолютной величине первой производной (скорости роста).
    $$Velocity = \frac{dI}{dt}$$
*   **Микро-тренды (Зарождающиеся сигналы):** Выявляются по метрике относительного ускорения. Редкий тег, внезапно получивший всплеск связности внутри локального кластера, детектируется как аномалия:
    $$Acceleration_{rel} = \frac{1}{I(t)} \cdot \frac{d^2I}{dt^2}$$

## 5. Инженерный Data Pipeline

Система спроектирована как асинхронный конвейер потоковой обработки:

1.  **Ingestion & Embedding Layer:** Текстовый поток проходит через легковесные модели (например, `all-MiniLM-L6-v2`), формируя векторы в пространстве $\mathcal{H}$.
2.  **LLM Tagging (Batch Layer):** Посты передаются в LLM (например, `Llama 3` через vLLM) с форсированным структурированным выводом (Structured Outputs) для извлечения массива пар `(Tag, Weight)` и цепочки рассуждений.
3.  **Graph Storage:** Транзакционное обновление графовой СУБД (Neo4j / PostgreSQL + Apache Age), где формируются узлы реификации `TagAssignment`.
4.  **Calculus Engine (CRON):** По расписанию генерируется `IndexSnapshot`. Пересчитываются $W_{stat}$ и $W_{temp}$, применяется фильтрация временных рядов, вычисляются градиенты (производные) и обновляются ребра `APPEARS_IN_TIMEFRAME`.

---

## 6. Научная новизна и практическая значимость

*   **Новизна:** Интеграция семантического анализа LLM с топологией реифицированного графа и применение аппарата функционального анализа и дифференциального исчисления для нормализации метрик и выявления неявных зависимостей в дискретных рядах.
*   **Практическая значимость:** Построенная архитектура может служить ядром систем раннего предупреждения (Early Warning Systems) для мониторинга микро-трендов, аудита бизнес-процессов, анализа рыночных настроений и выявления информационных каскадов.
